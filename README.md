# Union-Programs-in-c

C Union Programs

## Overview

This repository contains C programs demonstrating the concept of unions. These programs help in understanding memory sharing, union declaration, accessing union members, and the difference between structures and unions.

The programs are useful for:

- Beginners learning C programming
- College laboratory exercises
- Coding interview preparation
- Logic-building practice
- Understanding memory optimization
- Embedded systems programming fundamentals

---

## Programs Included

### 1. Basic Union Demonstration

This program demonstrates how union members share the same memory location.

#### Output Example

```text
a = 100
b = 12.50
a = 1095237632
```

#### Concepts Used

- Union declaration
- Shared memory concept
- Memory overwrite behavior
- Union member access

---

### 2. Sensor Data Using Union

This program demonstrates the use of a union for storing sensor-related data such as temperature and voltage.

#### Output Example

```text
Temperature = 30
Voltage = 3.30
```

#### Concepts Used

- Union initialization
- Embedded systems simulation
- Shared memory management
- Data handling using unions
